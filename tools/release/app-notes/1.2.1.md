A fix for iPhone and iPad.

- The strip at the bottom of the screen, where the home indicator sits, is no longer an empty grey bar: the tab bar, or the side rail in landscape, now reaches the bottom edge, with its buttons above the home indicator.
- On a phone held sideways, the side rail's buttons scroll instead of the last one being cut off.

## Updating

From 1.1.0 or later, use the Update button in the app. From 1.0.0, install this version by hand once.

| | |
|---|---|
| macOS 12 or later | `koebelt-dash-1.2.1-macos.dmg` |
| Windows 10 or later (x64) | `koebelt-dash-1.2.1-windows-x64-setup.exe` (not code-signed yet: if SmartScreen stops it, choose More info, then Run anyway) |
| Linux (x64) | `koebelt-dash-1.2.1-linux-x64.tar.gz` |
| Android 7 or later | `koebelt-dash-1.2.1-android.apk` |
