koebelt dash now updates itself. From this version on, the downloads from GitHub check for a new release when they start and once a day, and install it in one click.

## Updates in one click

- When a new version is out, an **Update** button appears in the top bar and in Settings > Updates, with what changed. Press it and koebelt dash downloads the new version, checks it against the release, and restarts on it. On Android, the system asks you to confirm the install.
- The download is checked against the checksums published with the release; on macOS the new app must also be signed by koebelt and accepted by Gatekeeper. Nothing is installed if a check fails.
- Updating closes the app, so it never starts while a connected device is armed, and it warns you when devices will disconnect.
- You can skip a version, or turn off the automatic check in Settings > Updates. The check only asks GitHub for the latest release.
- iPhone and iPad keep updating through TestFlight.

## Also

- macOS: koebelt dash now runs outside the App Sandbox, which a self-updating app needs. On the first launch, your settings and recordings from 1.0.0 are copied across.
- Settings, and the version the app reports to your devices, now show the right version (1.0.0 said 0.9.2).

## Updating from 1.0.0

1.0.0 cannot update itself yet, so install this version over it once, the same way as before. From 1.1.0 on, updates are one click.

| | |
|---|---|
| macOS 12 or later | `koebelt-dash-1.1.0-macos.dmg`: open it and drag koebelt dash to Applications, replacing the old one. |
| Windows 10 or later (x64) | `koebelt-dash-1.1.0-windows-x64-setup.exe`. Not code-signed yet: if SmartScreen stops it, choose More info, then Run anyway. |
| Linux (x64) | `koebelt-dash-1.1.0-linux-x64.tar.gz`: extract it, run `./install.sh` in the new folder so the menu entry points at it, and delete the old folder. |
| Android 7 or later | `koebelt-dash-1.1.0-android.apk`: it installs over 1.0.0 and keeps your data. |
