koebelt dash now knows which koebelt/link versions it works with, warns you before an update would leave one of your devices behind, and lets you install any version you want.

## Compatibility with your devices

- Each device reports its koebelt/link version when it connects, and koebelt dash remembers it.
- Before an update, koebelt dash checks which library versions that release supports. If one of your devices runs a version it no longer supports, the update says which devices and what to do: update their library first, or keep your version. You can still update anyway.
- A connected device whose library this version does not support shows in the alert chip at the top, with what to do.
- This release works with every koebelt/link version published so far (1.0.0 and later).

## Choose your version

- Settings > Updates > Versions lists every release, with whether it works with your devices, and installs any of them, older ones included. After you pick an older version on purpose, koebelt dash stops reminding you about the newest one until the next release.
- On Android, going back to an older version means uninstalling first; koebelt dash explains this rather than trying.

## Also

- macOS: the disk image opens on a designed window. Drag koebelt dash onto Applications.
- iPad: a long recording name in the replay header no longer runs over the buttons.

## Updating

From 1.1.0, use the Update button in the app. From 1.0.0, install this version by hand once.
