- Automatiser : une seule page pour les deux façons d’automatiser un appareil, les Séquences (des étapes dans l’ordre, sans code) et les Scripts (Python), avec un guide pour choisir.
- Scripts : pilotez vos appareils en Python avec n’importe quelle bibliothèque (OpenCV, PyTorch, YOLO). Écrivez-les, vérifiez-les et modifiez-les dans l’app ; ils s’exécutent sur un ordinateur de votre réseau, appairé une fois comme hôte de scripts, tandis que votre iPhone ou iPad garde la liaison, les manches et STOP.
- Les images et graphiques de vos scripts s’affichent dans Direct, et sont gardés avec l’enregistrement.
- Déclencheurs : lancez les actions d’un script par des boutons, des touches, une manette, des conditions comme battery.pct < 25 for 3s, des événements de l’appareil ou des minuteries.
- Vous gardez la main : STOP arrête tous les scripts, bouger les manches reprend le contrôle, et chaque script a les limites que vous fixez.
- Des modes plus simples : un appareil se connecte désarmé en HOLD, l’armer vous le confie en MANUAL, et AUTO seulement pendant qu’une séquence ou un script le pilote. Le mode s’affiche et se choisit dans Direct.
- Les capteurs de proximité s’affichent dans Direct, avec une alerte quand un obstacle est proche.
- Assistants IA : activez Réglages > Assistants IA pour qu’un client MCP comme Claude, sur votre ordinateur, lise les guides, écrive des scripts et utilise l’app. Les actions sur du matériel réel attendent votre accord.
- Cartes Mapbox : Sombre, Plein air et Satellite.
- Tous les écrans s’adaptent : petits iPhone, iPhone à l’horizontale, iPad à la verticale, et grands textes.
