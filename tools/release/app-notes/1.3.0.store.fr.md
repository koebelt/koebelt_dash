- Scripts : pilotez vos appareils en Python avec n’importe quelle bibliothèque (OpenCV, PyTorch, YOLO), depuis un nouvel écran Scripts sous Programme. Écrivez-les et modifiez-les dans l’app ; ils s’exécutent sur un ordinateur de votre réseau, appairé une fois comme hôte de scripts, tandis que votre iPhone ou iPad garde la liaison, les manches et STOP.
- Déclencheurs : lancez les actions d’un script par des boutons, des touches, une manette, des conditions comme battery.pct < 25 for 3s, des événements de l’appareil ou des minuteries.
- Vous gardez la main : STOP arrête tous les scripts, bouger les manches reprend le contrôle, et chaque script a les limites que vous fixez.
- Assistants IA : activez Réglages > Assistants IA pour qu’un client MCP comme Claude, sur votre ordinateur, lise les guides, écrive des scripts et utilise l’app. Les actions sur du matériel réel attendent votre accord.
