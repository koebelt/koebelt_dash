A small fix for iPhones held upright.

- **iPhone, upright:** the tab bar sits a little higher, so the labels of the outer tabs are no longer cut by the screen's rounded corners.

## Updating

From 1.1.0 or later, use the Update button in the app. From 1.0.0, install this version by hand once.

| | |
|---|---|
| macOS 12 or later | `koebelt-dash-1.2.3-macos.dmg` |
| Windows 10 or later (x64) | `koebelt-dash-1.2.3-windows-x64-setup.exe` (not code-signed yet: if SmartScreen stops it, choose More info, then Run anyway) |
| Linux (x64) | `koebelt-dash-1.2.3-linux-x64.tar.gz` |
| Android 7 or later | `koebelt-dash-1.2.3-android.apk` |
