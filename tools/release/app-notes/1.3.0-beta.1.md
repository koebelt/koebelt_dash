**Beta.** The first beta of koebelt dash 1.3: scripts and AI assistants. It is offered only to apps with Settings > Updates > Betas on; please report problems on GitHub.

koebelt dash now runs your Python scripts, with any package you like, and lets AI assistants help you, with the operator always in charge.

## Scripts

- **Drive a device from Python.** A new Scripts screen (under Program on phones) holds your scripts: create one from a template, import a `.py` or a `.zip` with its files, start from eight examples, edit in the built-in editor (colours, completion for the API, a syntax check), and run it on any connected device, simulated ones included.
- **Any Python package.** Scripts run in your own Python, so OpenCV, PyTorch and YOLO work: the camera arrives as NumPy images, newest first, and `dev.overlay()` draws what your model sees over the camera in dash. The first time, *Set up Python* prepares an environment with the `koebelt-dash-scripts` package.
- **Steps and programs.** Scripts take off, fly or drive to points, land, move arms and run your Program sequences, each returning once done.
- **Triggers.** Fire a script's events from a button or a switch (also on Control, next to the sticks), a key, a controller button, a condition (`battery.pct < 25 for 3s`), a device event or a timer.
- **You stay in charge.** STOP ends every script. Moving the sticks takes over until you resume. Each script has limits you set (speed, geofence, ceiling; no arming or parameter writes unless allowed). If a script crashes, hangs or leaves its geofence, the device holds and the script waits for you.
- **Phones and tablets** run scripts on a *script host*: any computer on the same network running `koebelt-dash-scripts host`, paired once with a code. The phone keeps the device link, the sticks and STOP.

## AI assistants

- Turn on Settings > AI assistants to let Claude, Cursor or another MCP client read the guides, look at your devices and recordings, write and test scripts on simulated devices, and use the app.
- On real hardware, every action an assistant takes waits for your approval on a card in dash. You can allow a kind of action for the session; arming and take-off always ask. STOP never asks, and safety settings stay out of reach.
- koebelt dash sends nothing to any AI service itself.

## Updating

From 1.1.0 or later: turn on Settings > Updates > Betas, then use the Update button, or choose it in Settings > Updates > Versions. From 1.0.0, install this version by hand once. The final 1.3.0 will be offered to everyone when it is out.
